## 便宜在哪：CN2 GIA 和普通德国 VPS 的区别

德国机房到国内的物理距离摆在那里，光速也救不回来，所以“快不快”拼的是路由走哪条线。普通德国 VPS 走电信 163 骨干网（AS4134），联通走 AS4837，移动走 CMI，晚高峰拥堵是常态，延迟从 180ms 跳到 400ms、丢包率上到两位数都不稀奇。CN2 GIA 走的是电信下一代承载网（AS4809，59.43 节点），专为高品质业务设计，晚高峰的波动小得多。

AkkoCloud 法兰克福机房的路由策略是：电信去程和回程都走 CN2 GIA，移动去程 CMI 直连、回程走 CMIN2 精品网。联通去程存在两种说法，一处写 CN2 GIA，一处写 AS4837，没有更新的官方信息能判断哪个是当前状态，所以别把“联通双向 GIA”当成确定事实，实际以你自己跑出来的路由为准。

延迟方面，第三方文章给出的数据是国内多地平均 ping 约 177ms，电信、联通大致 170ms 出头，移动稍高一些；另一处写法兰克福到国内普遍在 180ms 左右。这些是文章作者的口径，不是官方 SLA，不同省份、不同运营商会有差异。官方提供测试 IP **185.217.109.94**，下单前自己 ping 一下、跑个 traceroute，看回程是不是 59.43 开头，比看任何评测都直接。官方还有法兰克福机房的 Looking Glass，搜 AkkoCloud Looking Glass 能找到入口。

## 常见问题

**299 元年付和 99 元季付差在哪？**
配置完全一样：1 核、512MB 内存、10GB SSD、500GB 双向流量。差别在带宽（年付标称 1000Mbps，季付 500Mbps）、单位成本（24.9 元/月对 33 元/月）和资金占用。年付一次性付 299 元且不退款，季付可以按三个月为周期退出。

**A2 mini 到底是 768MB 还是 1GB？**
两个来源分别写 768MB 和 1024MB，价格都是 449 元/年。没有官方价格页可以裁定，下单时看结算页的实际配置。冲着 1GB 内存去的，付款前多看一眼。

**流量双向计算具体影响什么？**
上传和下载都算进月额度。以 A2 的 800GB 为例，如果你每月从服务器下载 500GB、上传 400GB，就已经超了。做备份、同步、网盘类业务要按上传侧单独估算。

**不退款的话，怎么降低风险？**
选最短的计费周期先跑。季付 99 元或 149 元是最低的试错成本，月付 50 元起也能用。确认延迟、路由、磁盘 IO 都符合预期，再考虑年付。

**U 系列不限流量，带宽为什么只有 30Mbps？**
不限流量和千兆带宽是两条产品线。U 系列卖的是流量不设上限，代价是端口限速在 30 到 200Mbps。真要千兆口又不限流量，价格不会是 1200 元/月这个量级。
